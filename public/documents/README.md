# Documents du portfolio

Déposez ici vos PDF et fichiers annexes, puis mettez à jour les liens dans
`src/data/site.ts` (champs `cv`, `annexes`, `proof`, et les `annexes` de chaque
réalisation).

Fichiers attendus par défaut :

- `cv.pdf` — CV à jour (lien « Télécharger mon CV »)
- `attestation-stage-1.pdf`, `attestation-stage-2.pdf`
- documentation technique et scripts des réalisations

Vérifiez qu'aucun document ne contient d'information confidentielle
(noms de clients, adresses IP réelles, captures internes) avant publication.
